# Proyecto Daddy Yankee PRRR

## Descripción
Este proyecto consiste en una página web de estilo documental que presenta la historia y el testimonio de Daddy Yankee después de su encuentro con Cristo al rededor del 2023 hasta hoy en día.

La página busca mostrar parte de su trayectoria, su transformación personal y su nuevo propósito.

## Características
- Portada de entrada.
- Menú de navegación.
- Diseño desarrollado con HTML y CSS.
- Funcionalidades implementadas con JavaScript.
- Imágenes relacionadas con la historia.
- Sección dedicada al álbum *Lamento en Bailes* y al nuevo llamado *La Postal*.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- Git y GitHub
